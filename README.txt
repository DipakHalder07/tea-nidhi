Nidhi Tea — Static HTML Experience (Homepage)

Folder contents:
  index.html     Full page: markup + CSS + JS in one file
  GEMINI.md      Comprehensive AI guide & design/animation rules
  AGENTS.md      AI assistant instruction rules
  README.md      Complete project documentation
  element-img/   Transparent organic botanical & tea assets
  img/           Tea packaging packs, hero renders & brand logo
  assets/        Supporting SVG icons & graphics
  nidhi-tea-cinematics-.mp4  4K tea story cinematic video

How to run:
  Open index.html directly in a browser, or serve the folder:
    python -m http.server 8000   ->  http://localhost:8000

Notes:
  - Tailwind CDN + Google Fonts (Anton + Inter Tight) + GSAP 3.12.5 & ScrollTrigger CDN.
  - See GEMINI.md for full animation documentation, safe edit zones, and strict do-not-touch rules.
